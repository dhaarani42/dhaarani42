## Run Locally

```bash
git clone https://github.com/dhaarani42/portfolio_nm.git
cd portfolio_nm
```

Then open `index.html` in your browser.

## Deploy on GitHub Pages

1. Rename `portfolio.html` to `index.html` and push it to the repository.
2. Go to **Settings → Pages**.
3. Under **Source**, choose **Deploy from a branch**, select `main` and `/ (root)`, then click **Save**.
4. After a minute, your site will be live at `https://dhaarani42.github.io/portfolio_nm/`.
